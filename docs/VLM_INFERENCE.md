# Live VLM Inference

The default quick-start examples use fixed reaction prompts generated by the
VLM. To run the complete brain-renderer pipeline, expose a multimodal VLM
through an OpenAI-compatible API. For example, a compatible vLLM deployment
can be started on separate GPUs as follows:

```bash
CUDA_VISIBLE_DEVICES=6,7 python -m vllm.entrypoints.openai.api_server \
  --model "$EW_VLM_CHECKPOINT" \
  --served-model-name Qwen3.8-27B \
  --port 8001 --trust-remote-code
```

Configure the endpoint and run the bundled examples in live-reasoning mode:

```bash
export EW_VLM_URL=http://127.0.0.1:8001/v1
export EW_VLM_MODEL=Qwen3.8-27B
export EW_VLM_THINKING=0

EW_USE_LIVE_VLM=1 \
EW_DEMO_GPUS="0" \
bash scripts/infer_examples.sh --case media/example1
```
